# Changelog

All notable changes to SWSANS are documented in this file.

## [0.1.0] - 2026-11-16

Initial public beta release.

- Tested Python core for randomly oriented Stoner-Wohlfarth ensembles.
- Uniaxial, cubic, and additive aligned uniaxial-cubic anisotropy models.
- Deterministic low-discrepancy Sobol orientation sampling.
- Projected Euler and projected Heun Landau-Lifshitz relaxation.
- Complete triangular field cycles with convergence diagnostics.
- First magnetization moments and full second-order correlation tensors.
- Saturation, descending-remanence, and descending-coercive states.
- Unpolarized and polarization-averaged spin-flip magnetic SANS observables.
- Perpendicular and parallel scattering geometries.
- Two-dimensional detector maps, azimuthal averages, pair-distance
  distributions, correlation functions, and CSV export.
- Browser-native Shiny/Shinylive interface with local calculations.
- Scientific model, coordinate conventions, migration notes, and regression
  tests.
